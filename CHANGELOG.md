# Changelog

## 0.28.3

### Changed

- Moth’s own code, build scripts and documentation use GNU GPL version 3 or later (`GPL-3.0-or-later`). Third-party components retain their existing licences.
- Contribution commits require a DCO sign-off.
- Modified forks must use a different name, icon and logo under the separate branding policy.
- Wumpus Mono Pro remains proprietary, with a separate permission for the bundled font files.

Earlier releases retain their original code and font licences. The historical terms are preserved in `licences/`.
